## レビュー観点：セキュリティ（OWASP ベース）

攻撃者の視点に立ち、今回の変更によって導入または悪化するセキュリティ上の欠陥を確認してください。主な確認項目は次のとおりです。

1. **アクセス制御・認証・認可**
   - 認証チェックや権限チェックの欠落・迂回、対象リポジトリ／PR／ワークスペース境界を越えるアクセス
   - 既存の認証方式確認や外部書き込み前の検証が緩んでいないか
2. **インジェクション・入力処理**
   - コマンドインジェクション、シェル演算子やオプション注入（省略形・連結形を含む）、パストラバーサル、XSS、SQL・テンプレート・正規表現インジェクション
   - リポジトリ内のファイル本文や外部入力を通じたプロンプトインジェクションにより、意図しないコマンド実行や書き込みが起きないか
3. **機密情報の保護**
   - API キー・トークン・認証情報のハードコード、子プロセスへの不要な環境変数引き継ぎ、ログ・エラー出力・成果物ファイルへの機密情報漏えい
4. **安全でない設定・権限境界の後退**
   - サンドボックス・読み取り専用ルール・承認ポリシーの緩和、ブラックリスト方式の回避経路、失敗時に安全側へ倒れない（フェイルオープン）設計
5. **ファイル操作・外部通信**
   - 実行権限の不要な付与、シンボリックリンクや一時ファイルの競合、未検証 URL へのリクエストや意図しない外部送信

変更に起因しない一般的なセキュリティ助言や、成立根拠のない仮定は報告しないでください。
