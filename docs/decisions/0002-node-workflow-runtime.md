# ADR 0002: Node.js 24でワークフローを実行する

- 状態: 採用
- 日付: 2026-11-08

## 背景

ワークフローの入口と共通部品をフォルダー単位でコピーして使えるようにし、生成されるキャッシュや追加パッケージの管理を減らしたい。[[ADR-0001]]ではPythonのライブラリ配置を決めたが、実行環境をNode.jsへ移行する。

## 決定

- miseでNode.js 24の最新版を指定し、標準機能とES modulesを使う。
- 公開するタスクを`.mise/tasks/`配下に置き、再利用する部品を各タスク群の`_lib/`に置く。
- Node.jsの部品は相対パスでimportし、実行権限を付けない。公開するタスクには実行権限を付ける。
- macOSとLinuxでは、コピー後のタスク検出、Docsの操作、代替CLIによるレビューをNode標準のテストで確認する。

## 影響

Node.js 24とmiseがあれば、追加パッケージやビルドを用意せずにタスクを実行できる。Node.js版のAI CLIへの実接続とWindowsでの動作は引き続き検証する。
